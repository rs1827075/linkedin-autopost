## Post text (edit freely, this is what gets published)

Building enterprise user interfaces on Salesforce used to mean relying entirely on LWC or Visualforce, which made integrating external web stacks quite challenging. Thankfully, the multi-framework landscape is evolving.

With the Winter ’27 release, Angular joins React as the second generally available UI framework alongside GA microfrontends, managed packaging, and localization support.

Picture a case where your wealth management team wants to embed an existing Angular-based portfolio calculator directly inside a Financial Services Cloud record page without rewriting the entire module from scratch. Multi-framework GA helps make that architectural pattern officially supported.

For enterprise Financial Services Cloud implementations, this matters because client portal experiences and advisor dashboards often rely on diverse tech stacks that need to coexist securely on a single platform.

How are you approaching modern UI architecture within your Salesforce orgs this year?
