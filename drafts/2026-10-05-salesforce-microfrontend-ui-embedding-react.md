## Post text (edit freely, this is what gets published)

Integrating external JavaScript applications into Salesforce has historically meant heavy workarounds with iframe wrappers or complex LWC rewrites. This friction slows down teams trying to deliver unified advisor workspaces.

Salesforce Microfrontend UI Embedding introduces lightning-ui-embedding, a capability letting you embed a React application directly into a record page and pass down the recordId context.

Picture a case where your wealth management team needs a custom portfolio visualization built in React, embedded directly inside a Financial Services Cloud account record without forcing users to jump to an external tab.

For enterprise Salesforce architectures, this approach helps decouple front-end UI delivery from the core platform while keeping the necessary record context intact for advisors.

How are you currently handling custom React components inside your record pages?
