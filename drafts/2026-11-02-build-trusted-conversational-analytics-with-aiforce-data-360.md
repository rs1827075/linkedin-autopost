## Post text (edit freely, this is what gets published)

Delivering AI insights in financial services often fails when different tools define core metrics like net worth or liquidity in conflicting ways.

Salesforce recently highlighted how combining AIforce, Data 360, and Tableau Semantics helps teams build shared business definitions that power consistent conversational experiences.

Picture a case where an advisor asks an AI agent about a client's total assets, and instead of guessing based on raw table joins, the agent references a centralized semantic layer to return the exact, verified calculation every time.

For enterprise orgs handling sensitive wealth data, this approach reduces the risk of hallucinated metrics and ensures compliance officers can audit exactly how calculations are derived across client touchpoints.

How is your team currently handling metric governance when exposing financial data to conversational AI agents?
