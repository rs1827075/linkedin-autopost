## Post text (edit freely, this is what gets published)

Moving custom workflows off legacy managed package runtimes is usually tedious, especially when dealing with deeply nested components. Fortunately, recent updates focus on streamlining this transition.

Salesforce has highlighted the Omnistudio Migration Assistant (OMA) to help automate the conversion of components and reduce manual effort when moving to the standard runtime.

Picture a case where you have a complex wealth management onboarding flow running on the managed package infrastructure. Using the migration assistant automates the heavy lifting of translating those assets, cutting down the days of manual XML adjustments typically required for enterprise environments.

For Financial Services Cloud implementations handling sensitive client data, moving away from managed package runtimes helps align deployments with core platform services and improves long-term maintainability.
