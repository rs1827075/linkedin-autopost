## Post text (edit freely, this is what gets published)

Testing your agent logic in a browser preview is great, but getting it to handle actual inbound telephone calls is where things get real for enterprise deployments.

Salesforce has rolled out Agentforce Voice for Agent Script, enabling developers to route real phone calls directly to your configured agent without rewriting its core logic.

Picture a case where a wealth management client dials in with a quick portfolio question, and your voice-enabled agent picks up the line seamlessly using the same underlying script you already tested in the sandbox.

For Financial Services Cloud implementations, this opens up practical avenues for automating routine client inquiries over the phone while keeping the architecture clean and consistent.
